Welcome to my Chess Engine, called DumbFish

This project was one of my favourites, as I have been playing chess for a long time, and it amazes me that I was able to build a robot capable of matching and sometimes defeating me in a few days!
This bot is roughly around 1600 Elo, though that is my best estimate. 
Eventually, I want to improve this bot and potentially make a physical version.
